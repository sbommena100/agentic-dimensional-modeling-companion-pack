# agentic-dimensional-modeling-companion-pack
Reader companion workbooks for Agentic Dimensional Modeling

Agentic Dimensional Modeling — Companion Pack

The companion pack contains ten ARDM workbooks covering the practitioner activities referenced in the book, together with a Reader Guide explaining the ADM-to-ARDM mapping and recommended workbook sequence.  

Download the latest companion pack from the Releases section of this repository.  

The worked solutions are reference designs. They illustrate defensible solutions rather than implying that every modeling problem has only one correct implementation.
